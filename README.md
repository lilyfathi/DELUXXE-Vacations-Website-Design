# DELUXXE Vacations

## Luxury Travel Website UI/UX Design

DELUXXE Vacations is a luxury travel website UI/UX design project focused on premium travel experiences in Sri Lanka and the Maldives.

The website was designed with a focus on luxury branding, intuitive navigation, clear information architecture, responsive web design principles, and interactive user experiences.

## Interactive Figma Prototype

The complete website prototype was designed and prototyped in Figma, including navigation, scrolling interactions, hover states, overlays, and interactive elements.

**[View Interactive Figma Prototype](https://www.figma.com/proto/ADrDV8R5X25hJfVytPEvYD/Deluxxe?node-id=537-6540&viewport=1717%2C-90%2C0.05&t=W8uopQcZn7z3GzuA-1&scaling=min-zoom&content-scaling=fixed&starting-point-node-id=301%3A7876&page-id=0%3A1)**
